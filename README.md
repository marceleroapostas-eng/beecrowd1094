# Beecrowd 1094 - Experiências

## Descrição
O programa recebe a quantidade de experimentos realizados em um laboratório e registra a quantidade de cobaias utilizadas em cada experimento, classificadas em coelhos, ratos e sapos.

Ao final, calcula o total de cobaias utilizadas, o total de cada tipo e o percentual de cada tipo em relação ao total.

## Linguagem
- Java

## Conteúdos praticados
- Estrutura de repetição for
- Estruturas condicionais if e else if
- Variáveis do tipo int, char e double
- Entrada de dados com Scanner
- Operadores de soma e atribuição
- Cálculo de porcentagem
- Formatação de saída com printf

## Entrada
A primeira linha contém um inteiro N, indicando o número de experimentos.

Cada uma das próximas N linhas contém um inteiro representando a quantidade de cobaias utilizadas e um caractere indicando o tipo de cobaia: C para coelho, R para rato e S para sapo.

## Saída
O programa apresenta o total de cobaias utilizadas, a quantidade de cada tipo e o percentual de cada tipo em relação ao total, com duas casas decimais.
